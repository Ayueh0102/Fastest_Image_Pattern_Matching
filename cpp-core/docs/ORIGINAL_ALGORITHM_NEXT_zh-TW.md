## 2. 實驗 A：自適應矩形投影＋保守 NCC 上界

**目的：在維持原 NCC 驗分的前提下，減少完整逐像素乘積。** 保留原金字塔、角度與位置範圍，模板建模時預先建立4→8→16→32→64個矩形的細分樹；容易排除的位置只看少數矩形。

2025年的 Segmented NCC 先將模板分割成矩形均值區，再以積分圖計算近似相關。2001年已有矩形基底的相關加速方法。這些並非本專案的新發明；本次提出的是結合現有投影上界，讓近似表示只協助排除，保留原模板完整驗分。[Segmented NCC 原論文](https://arxiv.org/abs/2502.01286)、[Briechle／Hanebeck 原論文](https://isas.iar.kit.edu/pdf/SPIE01_BriechleHanebeck_CrossCorr.pdf)。

令 `t` 與候選影像 `x` 均以整個模板支撐去平均，非零能量為 `Et=||t||²`、`Ex=||x||²`。將支撐分割成互不重疊且完整覆蓋的矩形，`P` 將每個矩形換成區域均值。`P` 是正交投影，故

```text
NCC(x,t) = [<Px,Pt> + <(I−P)x,(I−P)t>] / sqrt(Ex Et)

Uglobal = [<Px,Pt> + sqrt((Ex−||Px||²)(Et−||Pt||²))] / sqrt(Ex Et)
NCC(x,t) ≤ Uglobal
```

現有四區塊程式已用這類上界。新實驗增加兩個獨立變因：

1. **模板自適應細分。** 以每次切分可降低的模板平方誤差決定分區，平坦區保留大矩形，細節區多分。與論文的固定長邊二分、標準差門檻及 merge 不同，本探針使用模板誤差下降最大的二分，沒有 merge。
2. **逐區塊殘差界。** 對每個矩形 `b` 計算區域內去均值的殘差能量 `Ex,b`、`Et,b`，得到更緊的界：

```text
Ublock = [<Px,Pt> + Σb sqrt(Ex,b Et,b)] / sqrt(Ex Et)
NCC(x,t) ≤ Ublock ≤ Uglobal
```

兩個不等式來自 Cauchy–Schwarz；這是依本程式需求展開的推導，不宣稱為新論文定理。區域和、平方和可由積分圖取得；模板統計只需建模時算一次。區塊界多了平方和查詢與多次平方根，較緊不等於較快。

細分一塊為兩塊時，可用單一正交對比係數增量更新，避免每個階段重算所有區塊。若兩子區面積為 `n1,n2`、平均為 `μ1,μ2`：

```text
c(z) = sqrt(n1 n2 / (n1+n2)) × (μ1(z)−μ2(z))
projection_product += c(x)c(t)
projected_energy_x += c(x)²
projected_energy_t += c(t)²
```

**排除規則是 `U < 當前層門檻`，不是「近似 NCC < 門檻」。** 過不了上界排除的位置再算完整原 NCC。有限精度版本必須加入經分析的保守誤差界；靠近門檻、低方差或異常時回到原計算。本次探針的`1e-9`裕量只是數值診斷設定，不能當作已證明適用所有尺寸的生產安全界。

整合時另外保留四個契約：

- 低解析度 NCC 的上界只約束該層同一視窗；**不是高解析度或鄰近角度的上界**，不能據此任意砍掉整個姿態區間。
- 被選中峰值的 subpixel 擬合仍需完整3×3×3鄰域。被省略的鄰居要補算，不能把`−∞`交給擬合器。
- 常數模板／來源、近零方差、正負分數與飽和行為沿用`internal.hpp`，不能以純數學 NCC 公式取代既有邊界語義。
- 比較「完整 NCC」、「既有四區塊＋partial」、「自適應 global」、「自適應 block」；不能只拿無剪枝版本當唯一基準。

## 4. 實驗 B：原始 fine 的49個相鄰位置共用計算

現在 fine 每個角度先建立一張`(w+6)×(h+6)`旋轉ROI，再對7×7個位置分別計算`ΣI、ΣI²、ΣIT`。Metal各視窗有自己的SIMD群組，三種統計仍逐像素累加。

可分開測兩個等價改動：

- **正規化統計共用：** 在ROI上用整數滑動和／分離box sum一次得到49個`ΣI、ΣI²`，乘積保留原kernel。從每位置重掃模板改成共用計算；CPU核心已有積分圖，不能稱為全專案首次使用。
- **相鄰乘積重用：** 將第13輪只做在coarse的strip／tile方法重新設計給fine。先保留旋轉與repair不動，再比較每組同時計算多個相鄰輸出；不要一次把warp融合、精度及排程全部改掉。

49個視窗各看`wh`個像素，來源聯集只有`(w+6)(h+6)`個像素，表示有讀取重用機會；**乘積的模板相對位置不同，不能據此聲稱算術量或DRAM流量減少49倍**。需量實際GPU時間、buffer容量與全流程。256候選、不同模板大小及32／64-bit整數統計邊界都要覆蓋。

另外，同一anchor在角度括峰／加密時，現行`evaluateAngles`可能重算已評估的角度；先統計完全相同請求比例，才評估局部map快取。僅對影像、層級、模板、anchor與角度數值完全相同者重用；不能量化座標來偷換搜尋精度。

## 5. 實驗 C：模板預計算的連續細搜尋

Inverse-compositional配準把更新寫在模板端，使固定支撐、標準SSD等設定下的模板梯度、Jacobian與Hessian可預計算。ECC另有處理相關係數的反向組合推導。[Baker／Matthews](https://publications.ri.cmu.edu/lucas-kanade-20-years-on-a-unifying-framework-part-1)、[Evangelidis／Psarakis](https://pubmed.ncbi.nlm.nih.gov/18703836/)。

本專案已用`E=1−NCC`的解析求解，但當前正規化Jacobian取決於取樣後的來源與其能量。**不能把SSD的固定Hessian直接套上來，聲稱仍是同一個NCC求解器。**

先在相同粗候選、相同姿態信任區域下比較：原離散fine；現有LM逐層使用；再加獨立推導的IC／ECC。測固定尺度`(x,y,θ)`與相似變換`(x,y,θ,log s)`；每次更新以原完整NCC接受／拒絕，超預算或未收斂退回原fine。最終驗分只能避免接受低分解，不能保證找到原離散搜尋會找到的另一個高分峰。

這條線可能減少多張7×7角度map，但也可能縮小收斂範圍。亮度變化、薄線、角度步距邊緣、週期錯峰與尺度偏差應列為主要負控制。先測逐層fine替換，與末端LM更新法替換分開消融。

## 6. 實驗 D：旋轉基底／FFT的新搜尋表示

2D圓諧波方向可寫成近似模板族`Tθ ≈ Σm bm exp(imθ)`，先計算少量`I⋆bm`，再合成方向響應。Fageot等提供針對模板與背景模型設計steerable detector的研究；它是候選偵測器，不等同原NCC。[2021論文](https://arxiv.org/abs/1811.00863)。

Almira等的旋轉張量理論及ECCV2024實作是另一條有價值的路線，但後者驗證重點為3D tomography，不能直接引用為本專案2D速度。[旋轉NCC理論](https://arxiv.org/abs/2311.07561)、[張量實作](https://arxiv.org/abs/2408.02398)。

先做2D、固定尺度、相同全圖角度範圍的小原型，比較基底數、角度恢復誤差、候選召回、頻譜記憶體與完整NCC驗分成本。保留矩形模板的有效支撐：不能為了圓對稱而丟掉角落卻聲稱搜尋契約不變。尺度變化需另推導／建立尺度庫；steerable只處理旋轉，不自動處理尺度。

FFT則獨立比較「保留旋轉來源，只換每角度的平移相關」與「旋轉模板＋遮罩相關」。前者較容易沿用原支撐，後者需一致計算遮罩下的局部和、平方和。FFT本身沒有消除旋轉枚舉；這與早期全域log-polar配準不同。[Lewis原論文](https://scribblethink.org/Work/nvisionInterface/nip.html)、[既有遮罩推導](FIXED_SCALE_SEARCH_DESIGN_zh-TW.md)。
