# 第34輪：五項缺口的階段驗收計畫

基準為 `821fd77`，平台為目前 Apple M4 Pro／Metal。使用者確認目前沒有已標註的實拍序列；本輪以現有實拍模板、獨立合成幾何與保存的失敗案例完成有界驗證，不將合成通過宣稱為實拍泛化完成。

1. **尺度取樣偏差**：固定正確位置與角度，比較原雙線性、邊界支撐、等效模糊及前向渲染評分；加入其他模板、未調參 seed 與不同渲染模型。這是目標函數診斷，與實際搜尋端到端結果分開，±2%尺度門檻不變。
2. **遮擋與高分錯峰**：事前凍結 development／heldout 場景，包含條帶遮擋、近似非目標、接觸／互相遮擋；比較現行預算與有界擴搜，記錄候選捕獲、strict TP／FP／FN、時間與RSS。保留歷史高分週期錯峰。
3. **新影格生命週期**：新增獨立來源更新 API，保留模板模型、重建必須依附來源的資源；比較逐影格新建與重用，涵蓋尺寸變更。完整拆分讀圖、建立／更新、算法及釋放時間；不宣稱所有GPU資源都已重用。
4. **CPU／Metal精修公平比較**：獨立選擇精修後端，固定Metal前段、候選及求解預算。CPU使用合法獨立影像記憶體，Metal使用目前shared/u8方案，明確記錄表示差異。對6、128、512及小模板四種工作量，各12個正反順序配對block；first與repeat分開，配對輸出與GT分開。
5. **性能分布與最新組合穩定性**：上述獨立程序報中位數、描述性P95、配對差值及bootstrap區間，保留所有慢樣本；對最新512物件組合跑1800秒，逐次驗輸出、工作量、容量與RSS趨勢，約每100次重建Session。這是有界穩定性證據，不是任意時間無洩漏證明。

所有正式GPU工作串行；不與編譯、CPU密集實驗或其他GPU量測重疊。來源、執行檔、圖片與工作設定在量測前凍結並驗hash。速度容忍維持max(10%,2ms)，RSS比較max(10%,16MiB)，soak起末五分之一RSS增長max(10%,32MiB)。嚴格準確度仍為2px／1°／±2%，跨實作配對仍為0.25px／0.25°／0.2%／1e-4分數。

產出必須分列：實驗是否完整、比較是否公平、結果是否準確、速度是否改善；任何共同失敗繼續保留。若某項沒有改善，只得出其測試範圍內的否定／限制結論，不以放寬門檻、刪案例或未完成替代階段驗收。
