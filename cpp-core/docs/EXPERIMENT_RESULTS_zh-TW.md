## 搜尋策略對照

完整支撐組使用 256×256 source/template。每個顏色組有 4 個已知真值案例，包含旋轉 0°、31°、−47°、143°，尺度 0.8、1.0、1.1、1.2。平移先驗 ±12 px、角度全周、尺度 [0.75, 1.25]；所有方法共用最後七輪 4D NCC 局部網格精修。

Grid 用半解析度的 5,880 個位置／角度／尺度組合提出候選；Fourier 用 CPU NumPy FFT、log-polar 和 phase correlation 提出兩個 180° 分支，再用 NCC 選擇。Guarded 在候選越界或初始 NCC < 0.85 時回到 Grid。精修使用 7×81 個候選，最後回報實際評分過的姿態。

## 本次結論與適用範圍

1. 合併取樣＋NCC 的 GPU 批次值得繼續；大型工作量有收益，小批次須考慮提交／同步成本。尚未實作自動 CPU／GPU 分派。
2. Fourier 在符合整體相似變換假設的資料上可用；目前 CPU FFT 提案成本及暫存明顯，在這批小 ROI 的 Metal 管線中，直接批次網格搜尋更快。
3. 模板裁切、背景、遮擋會破壞假設。後續應先改善 ROI、mask、窗函數與候選保留策略，再研究 GPU FFT，不能直接刪除回退搜尋。
4. 本次尚未將研究後端接進正式 matcher／GUI；沒有全圖多尺度召回率、CUDA 實機結果或通用最快宣稱。CPU 尚可加入 SIMD／更好的 tile 重用；GPU 的相鄰姿態取樣也尚未共用。
