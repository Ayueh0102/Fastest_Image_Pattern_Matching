# 分階段重構計畫（Phased Refactor Plan）

本計畫由最小可行功能逐步擴展至完整功能，確保每階段皆可驗證、量測與回滾。

```mermaid
gantt
  title Python 版移植重構藍圖
  dateFormat  YYYY-MM-DD
  section 最小功能
  單尺度 NCC + CLI        :done,    f1, 2025-09-12, 1d
  section 效能與搜尋
  影像金字塔 + 區域化搜尋 :done,    f2, 2025-09-12, 1d
  角度粗到細搜尋           :done,    f3, 2025-09-12, 1d
  NMS/排序/報表            :done,    f4, 2025-09-12, 1d
  section 強化與驗證
  文件（含架構與移植差異） :done,    d1, 2025-09-12, 1d
  測試與基準               :active,  t1, 2025-09-12, 2d
  可選加速（FFT NCC）      :done,    a1, 2025-09-12, 1d
```

## 階段與驗收標準
- 階段 1：單尺度 NCC + CLI
  - 目標：輸入 Src/Tmpl，輸出 Top-K 位置與分數。
  - 驗收：能在 `Test Images/` 上得到合理結果（Score>0.5）。
- 階段 2：金字塔 + 區域化搜尋
  - 目標：縮小搜尋空間，維持或提升精度。
  - 驗收：相同輸入下，耗時下降，結果不退化。
- 階段 3：角度粗到細搜尋
  - 目標：支援旋轉不變性；粗步進找近似，細步進做精修。
  - 驗收：與原專案在代表性案例上角度接近（允許小誤差）。
- 階段 4：NMS/排序/報表
  - 目標：多目標去重疊，輸出友善（Index/Score/Angle/Pos）。
  - 驗收：多目標案例穩定、無明顯重複偵測。
- 階段 5：文件/測試/加速
  - 目標：完整 zh-TW 文件、冒煙/單元/基準測試、可選加速方案。
  - 驗收：CI 可跑基本測試；文件能輔助新成員快速上手。
