# 1. 專案概述

## 🎯 什麼是影像樣板比對？

影像樣板比對是一種電腦視覺技術，用來在大圖像中尋找特定的小圖樣（樣板）。就像在一張大地圖上尋找特定建築物一樣。

### 實際應用場景
- **工業檢測** - 在電路板上尋找特定零件
- **醫學影像** - 在 X 光片中定位特定結構
- **自動駕駛** - 識別交通號誌和路標
- **遊戲開發** - 自動化遊戲測試
- **品質控制** - 產品外觀檢測

## 🧠 核心技術概念

### 1. 正規化互相關 (NCC)
- **目的**: 測量兩個影像的相似度
- **輸出**: 相似度分數（0-1，越高越相似）
- **優勢**: 對光照變化具有抗性

### 2. 影像金字塔
- **概念**: 建立多種解析度的影像版本
- **策略**: 從小圖開始搜尋，逐層精修
- **效益**: 搜尋速度通常可提升數倍至數十倍

### 3. 角度搜尋
- **挑戰**: 目標可能旋轉任意角度
- **方案**: 粗到細兩階段搜尋
- **結果**: 精確的角度定位

### 4. 次像素估計
- **問題**: 整數像素定位精度有限
- **解法**: 3x3 鄰域二次曲線擬合
- **改善**: 次像素級精度定位
